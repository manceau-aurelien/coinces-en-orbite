Confidentialité

Ce site se visite librement, sans compte. Cette page explique ce qui est enregistré si vous créez un accès.

Ce qui est enregistré

  • Votre e-mail et votre mot de passe (le mot de passe est chiffré, personne ne peut le lire) : ils servent uniquement à vous connecter.
  • Votre pseudo, choisi à l'inscription.
  • Votre énergie perso : le nombre de rapports de quart, la date du dernier, et les notes de journaux que vous avez ouvertes.
  • Plus tard, votre progression dans les applications reliées à cet accès.

Ce qui n'est pas fait

  • Aucune publicité, aucun traceur, aucun cookie publicitaire.
  • Vos données ne sont ni vendues ni transmises à des tiers.
  • Votre e-mail n'est jamais affiché aux autres visiteurs.

Où sont les données

Les accès sont gérés par le service Supabase, qui héberge la base de données. Le site lui-même est hébergé par GitHub Pages. Votre navigateur garde aussi votre session de connexion (stockage local), pour ne pas vous redemander votre mot de passe à chaque visite.

Vos droits

Vous pouvez à tout moment supprimer votre accès : terminal CA-3 → « Mon accès » → « Supprimer mon accès ». Toutes les données liées sont alors effacées définitivement. Pour toute question, écrivez en commentaire sous une vidéo de la chaîne.
